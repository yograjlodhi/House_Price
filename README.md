# 🏠 House Price Prediction

## 📌 Project Overview
This project predicts house prices using Machine Learning based on various house features such as area, number of bedrooms, bathrooms, location, and other property-related attributes. The objective is to build an accurate regression model that can estimate house prices from input features.

---

## 🚀 Features
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Model Training & Evaluation
- House Price Prediction
- Performance Comparison of Multiple Regression Models

---

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## 📊 Machine Learning Models
- Linear Regression 

---

## 📈 Evaluation Metrics
- R² Score
